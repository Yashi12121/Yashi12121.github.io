Swarm Architecture

Four rules for coordinated intelligence without losing the thread.

Frontier models operate with complementary strengths: planning, coding, verification, and adversarial criticism.

Autonomous Task Delegation

The lead agent breaks down the problem, creates the roadmap, and automatically hands off sub-tasks to specialized crewmates: implementation to Codex, QA benchmarks to Gemini, and edge-case criticism to Grok.

Seamless Limit Failover

When Claude or GPT hits an hourly usage limit, YashiX automatically resumes with Gemini or local open-weights with the exact same memory and context.

Prompt Cache Engine

Rooms preserve a stable prefix across turns. Anthropic, OpenAI, and Gemini read cached tokens at a tenth of the price, saving up to 90% on API costs.

Real Shell Proof Verification

An agent's claim that tests passed is never trusted on text alone. YashiX executes actual local shell subprocesses and checks exit codes before proceeding.

100% Local & Private

All chats, memory logs, and API keys remain on your machine. Zero cloud telemetry. Full offline execution via Ollama and LM Studio.
