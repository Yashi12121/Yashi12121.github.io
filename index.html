02How it works

Four rules let several agents share a task without losing the thread.

2.1Crew


            
The first agent leads

            
The first agent in your crew answers you. Midway through a task it brings in a crewmate for the part that crewmate does better.

          

          

            
2.2Briefings

            

            
Crewmates start briefed

            
A crewmate gets the goal, what the room has learned, the files that changed and its own task. Only the lead reads the whole log.

          

          

            
2.3Limits

            

            
Work moves on at the limit

            
When an agent runs out of usage, the next one takes the same task with a briefing. YashiX shows the reset time and brings the first one back after it.

          

          

            
2.4Proof

            

            
Claims need a passing command

            
An agent can only say the tests pass when a test command passed after its last edit. Without one, the claim waits for you.

04Pool

          
Your plans work as one pool.

          
YashiX reads each plan's real limits through that tool's own login. You see what is left in every 5 hour window and every week, when each one resets, and which agent did best at each kind of work.

        

        
      

    


    
    

      

        
        

          
05Savings

          
Spend up to 90% less on tokens.

          
YashiX sets up every room for persistent prompt caching, so tokens the provider has already seen cost about a tenth of the price. On a plan that means more room before your limit. On an API key it means a smaller bill.

          
The Token Ledger shows real dollar savings per turn and per room.

        

      

    


    
    

      

        

          
06Side by side

          
Ask the whole crew at once and keep the best answer.

          
One message goes to every agent in the room, and the answers arrive in columns. The one you keep feeds that agent's rating, so Pool shows which agent wins at which kind of work.
