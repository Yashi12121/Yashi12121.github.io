01The room

You ask once and the agents pass the work between them.

A room is one shared conversation for one task, with your agents in it. Claude leads the plan, hands sub-tasks to Codex and Gemini, and checks proof.

02How it works

Four rules let several agents share a task without losing the thread.

2.1Crew

+---------+     brief     +---------+
| Claude  | ------------> |  Codex  |
|  (Lead) | <-----------  | (Build) |

     |

The first agent leads

The first agent in your crew plans the work. Midway through a task it brings in crewmates for the sub-tasks they excel at.

2.2Briefings

  Target: src/auth/jwt.ts
  Diff:   +42 lines, -6 lines
  Task:   Verify HMAC timing attack
  Status: [OK] No side-channel leak

Targeted briefings, not giant logs

Crewmates don't parse through thousands of lines of previous chat history. They receive clean, precise briefings with only what changed.

2.3Limits

  Claude Sonnet: [100% EXHAUSTED]
       │
       └── Seamless switch ──> Gemini 3.8 Flash
       (Full session context preserved)

Limit takeover

When Claude or GPT hits an hourly usage limit, YashiX automatically resumes with Gemini or a local model with the exact same memory.

2.4Proof

  Claim: "All tests pass"
  Check: git status --porcelain
  Run:   npm test > exit code 0
  Result: VERIFIED REAL PROOF

Proof checks

An agent claiming that tests passed or bugs were fixed is never believed on word alone. YashiX executes real shell proof to verify the exit code.
